# Clubset

Clubset is a student-friendly platform for managing school clubs in one place.

It brings club discovery, membership, events, attendance, communication,
leadership applications, finances, forms, and shared data into a single system.

> Clubset should do the complicated work behind the scenes so students only
> have to make simple decisions.

## Tech Stack

- TanStack Start + React
- Vite + Nitro
- Tailwind CSS + shadcn/ui
- Supabase (Postgres, Auth, Storage, Realtime)
- PostgreSQL Row Level Security (RLS)

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```
